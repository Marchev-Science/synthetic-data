Chapter 1.1 — Imputation by Category Mean#

A common imputation mistake is filling missing values with the global mean of a variable. When the variable has a strong relationship with a categorical grouping variable, the group mean is a far better estimate — it preserves the within-group distribution and avoids flattening real structure.

When to use this approach:

  • Missing values are suspected to be missing at random (MAR) conditional on a known categorical variable.

  • The categorical grouping explains meaningful variance in the numeric variable.

  • You need a fast, transparent, assumption-light imputation without a full ML pipeline.

import pandas as pd
import numpy as np

Setup — Create a Dataset with Missing Values#

# Seed for reproducibility
np.random.seed(42)

# Creating the DataFrame
data = {
    'Category': np.random.choice(['A', 'B', 'C'], size=10),  # Categorical variable with 3 categories
    'Numeric1': np.random.uniform(1, 100, size=10),  # First numeric variable
    'Numeric2': np.random.uniform(1, 100, size=10)   # Second numeric variable
}

df = pd.DataFrame(data)

# Introduce missing values randomly in Numeric1 and Numeric2
missing_indices1 = np.random.choice(df.index, size=3, replace=False)
missing_indices2 = np.random.choice(df.index, size=2, replace=False)

df.loc[missing_indices1, 'Numeric1'] = np.nan
df.loc[missing_indices2, 'Numeric2'] = np.nan

Imputation — Group Mean by Category#

Pandas groupby().transform('mean') computes the within-group mean and broadcasts it back to the original row index, so it can be used directly as a fill value.

print(df)

# Fill missing values within each category class with the mean of that class
df['Numeric1'] = df.groupby('Category')['Numeric1'].transform(lambda x: x.fillna(x.mean()))
df['Numeric2'] = df.groupby('Category')['Numeric2'].transform(lambda x: x.fillna(x.mean()))

print(df)

Summary#

Imputing with the category mean rather than the global mean avoids the distributional distortion that arises when subgroups have different means. The same pattern extends to other aggregates (median, mode) and to multiple grouping variables.

Related: Chapter 1.2 shows an alternative — filling with a noise sample drawn from the variable’s distribution — which preserves variance as well as the mean.
